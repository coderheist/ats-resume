Mode 3 — POST /bias-audit/jd

Scan a job description for coded-language skew

Flags a job post when agentic-coded language ("dominant," "aggressive") outweighs communal-coded language by a threshold, and suggests neutral rewrites — a simple, auditable word-list model rather than an opaque classifier.
